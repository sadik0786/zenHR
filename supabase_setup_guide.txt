STEP 3: Database Tables Design (SQL Editor)
-------------------------------------------
Go to the "SQL Editor" tab on the left and run this query to create your core SaaS tables:

```sql
-- 1. COMPANIES TABLE
CREATE TABLE companies (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  company_name TEXT NOT NULL,
  admin_name TEXT NOT NULL,
  admin_email TEXT UNIQUE NOT NULL,
  plan_id INT DEFAULT 1,
  status TEXT DEFAULT 'ACTIVE',
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 2. BIOMETRIC MACHINES TABLE
CREATE TABLE biometric_machines (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  device_name TEXT NOT NULL,
  ip_address TEXT NOT NULL,
  serial_number TEXT NOT NULL,
  company_id BIGINT REFERENCES companies(id),
  status TEXT DEFAULT 'Online',
  last_sync TIMESTAMPTZ DEFAULT NOW()
);

-- 3. EMPLOYEES TABLE (Linked to Company)
CREATE TABLE employees (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  company_id BIGINT REFERENCES companies(id),
  full_name TEXT NOT NULL,
  email TEXT UNIQUE NOT NULL,
  designation TEXT,
  joining_date DATE
);
```

STEP 4: Security (Row Level Security - RLS)
-------------------------------------------
This is the MOST IMPORTANT step for SaaS.
1. Go to Authentication -> Policies.
2. Enable RLS on all tables.
3. Add a policy: "Users can only see data belonging to their company_id".
   * This prevents Company A from seeing Company B's data.

STEP 5: Flutter Integration
---------------------------
1. Open `pubspec.yaml` and add:
   `supabase_flutter: ^2.0.0`
2. Run `flutter pub get`.
3. In `main.dart`, initialize Supabase:
   ```dart
   await Supabase.initialize(
     url: 'YOUR_SUPABASE_URL',
     anonKey: 'YOUR_ANON_KEY',
   );
   ```

STEP 6: Replacing Local Controller Logic
-----------------------------------------
Instead of local lists, your controller will now look like this:
```dart
final response = await supabase.from('companies').select();
companies.assignAll(response);
```

QUESTION: What about my existing Node.js Backend?
-------------------------------------------------
* You can keep using it! Node.js can connect to Supabase using the "Connection String" (Database Settings -> Connection String).
* Supabase will act as your Cloud Database.
* No need to manage SQL Server or MySQL on your own VPS. Supabase handles backups and scaling automatically.
